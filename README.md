# Extração de Nome de Arquivo em Java

Projeto simples em Java para praticar manipulação de Strings.

## O que foi utilizado

- `lastIndexOf()`
- `substring()`
- `Scanner`

## Objetivo

Aprender como separar o nome de um arquivo da sua extensão utilizando métodos da classe `String`.

## Como funciona

O programa:
- Recebe o nome de um arquivo
- Encontra a posição do ponto (`.`)
- Se existir extensão, separa o nome do arquivo
- Caso contrário, informa que não há extensão

## Exemplo

Entrada:
```
foto.png
```

Saída:
```
Nome do arquivo sem extensão: foto
```

## Tecnologias

- Java
